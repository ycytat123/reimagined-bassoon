# 超低音箱阵列计算器

Subwoofer Array Calculator — 弧形阵列 / 端射阵列 / 心形阵列

## 功能

三种超低音箱阵列模式的布局计算与 SPL 可视化：

- **弧形阵列 (Arc Array)** — 直线物理摆放 + 电子延时虚拟弧形波阵面，中心延时=0，边缘延时最大
- **端射阵列 (End-Fire Array)** — 前后排列，波束向前叠加、后方抵消
- **心形阵列 (Cardioid FBF)** — 水平 3 音箱 FBF 配置，中间反转+延时

### 计算输出

- 推荐间距（λ/2 或 λ/4）、实际间距、总宽度/深度
- 每只音箱的 X/Y 物理坐标（m）和延时（ms）
- SPL 声压级覆盖热力图（相干波叠加，3dB 色阶，双线性插值）
- 阵列布局示意图（包含虚拟弧波阵面）

## 技术细节

- 单文件 HTML，纯 JavaScript，无需任何依赖
- 声速固定 343 m/s（20°C）
- 相干波叠加：复振幅求和 → 20·log₁₀(|sum|/N)
- SPL 颜色：红(0dB) → 橙 → 黄 → 绿 → 深绿(-30dB)，每 3dB 一色阶
- 256 级预计算 LUT 颜色表 + 双线性插值渲染
